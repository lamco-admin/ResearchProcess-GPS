# ResearchProcess-GPS: A Vision for Modern Genealogical Research

## Executive Summary

ResearchProcess-GPS is a next-generation genealogical research platform that bridges the gap between traditional family tree software and professional research methodology. By leveraging GEDCOM 7 extensions as interoperability infrastructure, we're creating a collaborative research environment that works seamlessly with existing tools while enabling workflows that desktop software cannot provide.

## The Problem

Current genealogy software falls into two camps:
1. **Desktop Software**: Feature-rich but isolated, focused on conclusions not research process
2. **Online Platforms**: Collaborative but proprietary, designed for data lock-in not research workflow

Neither supports the actual work of genealogical research:
- Evidence evaluation and correlation
- Research planning and tracking
- Collaborative analysis
- Source assessment and citation
- Hypothesis testing
- Research logs and correspondence

## The Vision

ResearchProcess-GPS is a **research workbench** that:

### 1. Puts Research Process First
- Track research goals and tasks
- Document evidence evaluation
- Record negative searches
- Maintain research logs
- Support GPS (Genealogical Proof Standard) methodology

### 2. Enables True Collaboration
- Share research projects, not just trees
- Collaborative evidence analysis
- Peer review workflows
- Research group coordination
- Knowledge preservation

### 3. Integrates Seamlessly
- Import from any GEDCOM source
- Enhanced round-trip with GRAMPS
- Export to any genealogy software
- Preserve all data through extensions
- API-first architecture

### 4. Supports Professional Standards
- Evidence Explained citation methodology
- Source assessment frameworks
- Proof argument documentation
- Research report generation
- Audit trails and provenance

## Technical Strategy

### Core Architecture
- **Plugin-based platform**: Extensible by design
- **Event-sourced data model**: Full research history
- **API-first**: Everything accessible programmatically
- **Cloud-native**: Collaborative from the ground up

### Interoperability Through GEDCOM 7
Using carefully designed extensions:
- **Evidence Extension**: Track analysis and correlation
- **Occurrence Extension**: Share events across people
- **Citation Enhancement**: Element-level source data
- **Research Extension**: Goals, tasks, logs
- **Tag System**: Flexible categorization

### GRAMPS as Proof of Concept
- Open source allows deep integration
- Python enables rapid prototyping
- Active community provides feedback
- Desktop/research platform hybrid model

## Why This Will Succeed

### 1. Creates Its Own Demand
- Solves real problems genealogists face daily
- Provides capabilities no desktop software offers
- Makes collaboration actually work

### 2. Embraces Existing Ecosystem
- Not trying to replace desktop software

### 3. Open Development Model

### 4. Clear Value Proposition

## The Ask

We need the GEDCOM community to:
1. **Support practical extensions** that enable research workflows
2. **Prioritize implementability** over theoretical purity
3. **Focus on data portability** as a user right
4. **Recognize research process** as equal to conclusions

## Conclusion

ResearchProcess-GPS isn't trying to replace existing genealogy software—it's creating the missing research layer that works with everything else. By building on GEDCOM 7 with practical extensions, we can finally have both powerful research tools AND data portability.

The future of genealogy isn't locked platforms or isolated desktop software. It's an ecosystem where specialized tools work together, data flows freely, and research is preserved alongside conclusions.

**We're not just building software. We're enabling better genealogical research.**
