# Theory Versioning and Dynamic Tree Building
**Date**: July 29, 2025, 16:30 EEST  
**Concept**: The Killer Feature for ResearchProcess-GPS

## The Revolutionary Concept

ResearchProcess-GPS transforms genealogy from **static family trees** to **dynamic theory exploration**. Researchers can build multiple versions of family trees based on different hypotheses and quickly compare outcomes.

## Core Innovation: Liberation from GEDCOM Constraints

### GEDCOM Import → Entity Liberation
```yaml
GEDCOM_Liberation_Process:
  Import_GEDCOM7+:
    - Read person records with all extensions
    - Extract all evidence and sources
    - Preserve all relationships
    
  Decompose_into_Personas:
    Person_Record → Multiple_Personas:
      - John Smith (1850 Census) → Persona_1
      - John Smith (1860 Census) → Persona_2  
      - J. Smith (Marriage 1845) → Persona_3
      - John S. (Death 1880) → Persona_4
      
  Create_Identities:
    - Identity_A: "John Smith of Ohio"
    - Identity_B: "John Smith of Indiana"
    - Identity_C: "Unknown J. Smith"
    
  Float_Evidence:
    - Evidence no longer bound to specific persons
    - Can be reassigned to different identities
    - Can support multiple theories simultaneously
```

## Theory Versioning System

### Multi-Version Tree Building
```yaml
Theory_Trees:
  Base_Research:
    - Imported GEDCOM data
    - Decomposed personas
    - Floating evidence
    - Uncertain relationships
    
  Theory_Version_1:
    name: "Sam Jones died 1853"
    assumptions:
      - Sam Jones (persona_5) died in 1853
      - Therefore cannot be father of William (born 1856)
    implications:
      - Need different father for William
      - Sam's children need new timeline
      - Property inheritance changes
    
  Theory_Version_2:
    name: "Sam Jones died 1863"
    assumptions:
      - Death record was mistranscribed (1853→1863)
      - Sam Jones could be William's father
    implications:
      - Family structure remains intact
      - Property records now make sense
      - Military service records align
      
  Theory_Version_3:
    name: "Two different Sam Jones"
    assumptions:
      - Sam Jones Sr. died 1853
      - Sam Jones Jr. was William's father
    implications:
      - Explains conflicting records
      - Need to find evidence of Jr.
      - Changes entire family structure
```
