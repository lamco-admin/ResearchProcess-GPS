## Revolutionary Concepts Developed

### 1. Theory Versioning (The Killer Feature)
- Import GEDCOM → Liberate into flexible personas/identities
- Create multiple theories ("What if John died in 1853?")
- Evidence floats between theories
- Compare/merge theories like Git branches

### 2. Everything is Citable and Publishable
- Any entity can have working + published states
- Version control throughout
- Fork and build on others' research
- Full attribution chains

### 3. Unknowns as First-Class Citizens
- Track unknown identities with known attributes
- Unknown locations with constraints
- Research what you don't know
- Gradual resolution workflows

### 4. Privacy by Design
- Unified framework treats all data like DNA
- Four classification levels (RESTRICTED to PUBLIC)
- Consent management everywhere
- GDPR/provider compliance built in

## Technical Decisions Made

### Storage Strategy
- **Primary**: Git repositories (private, encrypted)
- **Enhanced**: PostgreSQL + Apache AGE for graphs
- **Flexible**: Adapters for JIRA, cloud services
- **User-friendly**: Hide Git complexity completely

### Development Stack
- **Backend**: Django (modular architecture)
- **Graph**: PostgreSQL + Apache AGE
- **Real-time**: WebSockets
- **Storage**: Git + database hybrid
- **Security**: HSM-backed encryption

### Implementation Phases
1. **Phase 1**: Core Django + Git storage + GRAMPS bridge
2. **Phase 2**: Clan features + imports + member portal
3. **Phase 3**: Graph analytics + plugin system
